A facility badge means the source lists that facility at the location. It is not the number of individual machines. Missing facility information means unknown availability.

Locations and district assignments

Pins retain the coordinates in the bank’s published direction links. These have not been independently surveyed. Missing coordinates and out-of-country or conflicting coordinates are withheld. Address search links open Google Maps searches and do not establish exact locations.

Districts are assigned from coordinates, source district fields, or a town reference. Some source fields and inferred assignments require review; each location shows its assignment method. Dotted badges are district summaries of records awaiting pins, not branch locations. Zero classified records is not evidence that a bank has no presence.

Geography and references

District boundaries: geoBoundaries LKA ADM2, OpenStreetMap / Wambacher, 2017 geography, ODbL 1.0. Town reference: SriLankaCitiesDatabase (MIT). Town coordinates are never used as branch pins.

This application reads local static data. Source and Google Maps links require internet access. No backend or paid map API is required.
